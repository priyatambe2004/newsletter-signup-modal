# Newsletter Signup Modal

A responsive newsletter signup popup that invites users to subscribe to updates through an email form. The modal appears after a short delay and can be dismissed easily.

## Features

- **Delayed Popup:** Displays the signup modal after a few seconds.
- **Email Validation:** Checks the email format before submission.
- **Dismissible Modal:** Close the popup using the close button or overlay.
- **Interactive UI:** Simple and user-friendly interface.
- **Responsive Design:** Adapts to different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download the repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser.
4. Wait for the modal to appear.
5. Enter an email address to test validation and submission.
6. Dismiss the modal using the close button or overlay.
